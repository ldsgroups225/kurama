## Feature Matrix

| Feature | Quiz Mode | Test Mode |
|---------|-----------|-----------|
| **Purpose** | Adaptive learning with spaced repetition | Formal assessment and exam simulation |
| **Configuration** | Learning objectives (3 modes) | Detailed settings (count, types, direction) |
| **Question Types** | Multiple choice, Written | Multiple choice, True/False, Written |
| **Feedback Timing** | Immediate (asymmetric: correct=800ms, incorrect=manual) | End of test only (no feedback during) |
| **Auto-Advance** | Correct: 800ms, Incorrect: Manual | All: 100-150ms (natural delay) |
| **Progress Display** | Badge counter (3/12) | Progress bar + counter (3/20) |
| **Question Adaptation** | Dynamic (based on performance) | Static (generated upfront) |
| **"Don't Know" Option** | ✅ Yes | ❌ No |
| **Audio/Star Buttons** | ✅ Yes | ❌ No |
| **Loading Screen** | ❌ No | ✅ Yes (2 seconds) |
| **Results Display** | Score card with XP | Donut chart with detailed breakdown |
| **Answer Review** | ❌ No | ✅ Yes (expandable list) |
| **Next Steps** | Restart or Home | Review missed terms, New test, or Home |
| **Color Theme** | XP (blue/purple gradient) | Streak (orange/amber gradient) |
| **Icon** | 📚 BookOpen | 🎯 ClipboardCheck |
| **Use Case** | Daily practice, skill building | Exam preparation, self-assessment |
| **Session Length** | Variable (until mastery) | Fixed (user-defined) |
| **Retry Mechanism** | Incorrect cards repeat | Full test restart |
| **Performance Tracking** | Session stats only | Complete answer history |

## User Experience Flow

### Quiz Mode Flow
```
1. Select "Quiz" mode
   ↓
2. Choose learning objective
   - Mémoriser tout
   - Réviser les favoris
   - Révision rapide
   ↓
3. Answer questions
   - See question
   - Select answer
   - Get immediate feedback
   - Correct: Auto-advance (800ms)
   - Incorrect: Review + Manual continue
   ↓
4. Complete session
   ↓
5. View summary
   - Score percentage
   - Correct/Incorrect count
   - Time and cards
   - XP earned
   ↓
6. Restart or Home
```

### Test Mode Flow
```
1. Select "Test" mode
   ↓
2. Configure test
   - Question count (5-60)
   - Instant correction (on/off)
   - Answer direction (term/definition)
   - Question types (T/F, MC, Written)
   ↓
3. Answer questions
   - See question
   - Select answer
   - Brief highlight (100-150ms)
   - Auto-advance (no feedback)
   ↓
4. Complete test
   ↓
5. Loading screen (2 seconds)
   - "Nous compilons vos résultats"
   ↓
6. View detailed results
   - Score percentage
   - Donut chart
   - Correct/Incorrect breakdown
   - Complete answer review
   - Next steps suggestions
   ↓
7. Review missed terms, New test, or Home
```

## Timing Comparison

### Quiz Mode Timing
```
Question Display:     0ms
User Thinks:          Variable
User Clicks:          0ms
Feedback Display:     Immediate
Auto-Advance:         800ms (correct only)
Manual Continue:      User-controlled (incorrect)

Average per question: ~5-10 seconds (with thinking)
12 questions:         ~1-2 minutes

```

```
User Thinks:          Variable

Average per question: ~3-5 seconds (with thinking)
20 questions:         ~1-2 minutes + 2s loading
```

## Design Language

### Quiz Mode
- **Color**: Blue/Purple (XP gradient)
- **Feel**: Encouraging, supportive, educational
- **Tone**: "Vous maîtrisez le sujet !"
- **Icons**: BookOpen, Target, Zap
- **Feedback**: Immediate and detailed
- **Motivation**: XP rewards, positive reinforcement

### Test Mode
- **Color**: Orange/Amber (Streak gradient)
- **Feel**: Formal, focused, exam-like
- **Tone**: "Vous êtes en train d'apprendre !"
- **Icons**: ClipboardCheck, Lock, RefreshCw
- **Feedback**: Comprehensive at end
- **Motivation**: Performance tracking, improvement suggestions

## When to Use Each Mode

### Use Quiz Mode When:
- ✅ Daily practice and skill building
- ✅ Learning new material
- ✅ Need immediate feedback
- ✅ Want adaptive difficulty
- ✅ Building confidence
- ✅ Earning XP and leveling up
- ✅ Short, focused sessions

### Use Test Mode When:
- ✅ Preparing for exams (BEPC/BAC)
- ✅ Self-assessment needed
- ✅ Want to simulate exam conditions
- ✅ Need detailed performance analysis
- ✅ Reviewing weak areas
- ✅ Tracking progress over time
- ✅ Longer, comprehensive sessions

## Technical Differences

### State Management

#### Quiz Mode
```typescript
// Simpler state
const [questionState, setQuestionState] = useState<QuestionState>('answering')
const [selectedAnswer, setSelectedAnswer] = useState<number | null>(null)
const [showAnswer, setShowAnswer] = useState(false)

// Immediate feedback
if (isCorrect) {
  setQuestionState('correct')
  setTimeout(() => onAnswer(true), 800)
} else {
  setQuestionState('incorrect')
  setShowAnswer(true)
  // Manual continue
}
```

#### Test Mode
```typescript
// More complex state
const [testSettings, setTestSettings] = useState<TestSettings | null>(null)
const [testAnswers, setTestAnswers] = useState<TestAnswer[]>([])
const [showTestLoading, setShowTestLoading] = useState(false)

// No feedback, just record
setIsAnswered(true)
setTimeout(() => {
  onAnswer(isCorrect, userAnswer)
}, 100) // Natural delay only
```

### Data Structures

#### Quiz Mode
```typescript
// Simple answer tracking
interface SessionStats {
  correct: number
  incorrect: number
}
```

#### Test Mode
```typescript
// Detailed answer tracking
interface TestAnswer {
  question: string
  userAnswer: string
  correctAnswer: string
  isCorrect: boolean
  questionType: string
}

interface TestSettings {
  questionCount: number
  instantCorrection: boolean
  answerWith: 'term' | 'definition'
  trueFalse: boolean
  multipleChoice: boolean
  written: boolean
}
```

## Performance Comparison

### Bundle Size
- **Quiz Mode**: ~400 lines of code
- **Test Mode**: ~1,000 lines of code
- **Shared Components**: Card, Button, Badge, etc.

### Runtime Performance
- **Quiz Mode**: Slightly faster (less state)
- **Test Mode**: Slightly slower (more tracking)
- **Both**: Optimized with memoization and GPU acceleration

### Memory Usage
- **Quiz Mode**: Lower (minimal state)
- **Test Mode**: Higher (stores all answers)
- **Both**: Negligible impact on modern devices

## Conclusion

Both modes serve distinct purposes in the learning journey:

**Quiz Mode** is perfect for daily practice, building skills, and earning rewards through adaptive learning with immediate feedback.

**Test Mode** is ideal for exam preparation, self-assessment, and comprehensive performance analysis in a formal testing environment.

Together, they provide a complete learning and assessment ecosystem for Kurama students preparing for BEPC/BAC exams in Côte d'Ivoire.
