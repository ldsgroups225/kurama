## Démarrage rapide

### Installation de l'application

Kurama est une Progressive Web App (PWA) qui peut être installée sur votre appareil :

**Sur navigateur desktop :**
- Cliquez sur l'icône d'installation dans la barre d'adresse
- Ou allez dans le menu → Installer Kurama

**Sur iPhone :**
- Appuyez sur Partager
- Sélectionnez "Ajouter à l'écran d'accueil"
- Appuyez sur "Ajouter"

**Sur Android :**
- Appuyez sur le menu (trois points)
- Sélectionnez "Installer l'application"
- Confirmez l'installation

### Première utilisation

1. Connectez-vous avec votre compte Google
2. Complétez votre profil (niveau scolaire, série, matières)
3. Commencez à étudier avec les flashcards

**Conseil :** Une fois installée, Kurama fonctionne comme une application native et peut être utilisée hors ligne.

## Fonctionnalités hors ligne

### Ce que vous pouvez faire hors ligne

- **Étudier avec les flashcards** - Accédez à vos leçons en cache et étudiez hors ligne
- **Suivre votre progression** - Vos réponses et votre XP sont enregistrés localement
- **Gagner des récompenses** - Continuez à gagner de l'XP, des niveaux et des succès
- **Contenu en cache** - Les leçons et flashcards sont automatiquement mises en cache

### Télécharger du contenu pour l'étude hors ligne

Pour vous assurer d'avoir accès à vos leçons préférées hors ligne :

1. Ouvrez une leçon
2. Cliquez sur le bouton "Télécharger pour l'étude hors ligne"
3. Attendez que le téléchargement soit terminé
4. Le contenu sera disponible même sans connexion

**Note :** Les téléchargements volumineux peuvent utiliser beaucoup de données mobiles. Utilisez le Wi-Fi si possible.

## Synchronisation des données

### Comment fonctionne la synchronisation

Kurama synchronise automatiquement vos données quand vous êtes en ligne :

- Vos réponses aux flashcards
- Votre XP et vos niveaux
- Vos succès et réalisations
- Votre progression générale

### Vérifier le statut de synchronisation

Regardez l'indicateur de synchronisation dans la barre de navigation :

- **Hors ligne** - Pas de connexion Internet
- **Synchronisation** - Données en cours de synchronisation
- **En ligne** - Connecté et synchronisé

### Résoudre les problèmes de synchronisation

Si vos données ne se synchronisent pas :

1. Vérifiez votre connexion Internet
2. Attendez quelques secondes - la synchronisation est automatique
3. Ouvrez le tableau de bord de synchronisation pour voir les détails
4. Cliquez sur "Réessayer" pour les mutations échouées

**Astuce :** Vos données sont toujours sauvegardées localement, même si la synchronisation échoue. Elles seront synchronisées dès que vous serez en ligne.

## Gestion du stockage

### Comprendre le stockage local

Kurama utilise le stockage local de votre appareil pour :

- Mettre en cache les leçons et flashcards
- Stocker votre progression et vos réponses
- Sauvegarder vos données de synchronisation
- Conserver votre session de connexion

### Vérifier l'espace disponible

Pour voir combien d'espace vous utilisez :

1. Allez dans Paramètres → Gestion du cache
2. Vous verrez l'espace utilisé et disponible
3. Consultez la liste du contenu en cache

### Libérer de l'espace

Si vous manquez d'espace :

1. Allez dans Paramètres → Gestion du cache
2. Cliquez sur "Effacer les anciennes données" pour supprimer les données obsolètes
3. Ou cliquez sur "Effacer tout le cache" pour une suppression complète
4. Vous pouvez aussi supprimer des leçons individuelles

**Note :** L'effacement du cache ne supprime pas votre progression. Vos données de progression sont synchronisées avec nos serveurs.

### Limites de stockage

Chaque appareil a une limite de stockage :

- **Desktop :** Généralement 50 MB à plusieurs GB
- **Mobile :** Généralement 50 MB à 500 MB
- Kurama gère automatiquement l'espace en supprimant les données anciennes

## Dépannage

### L'application ne fonctionne pas hors ligne

**Solution :** Assurez-vous que vous avez d'abord utilisé l'application en ligne pour que le contenu soit mis en cache. Téléchargez explicitement les leçons que vous souhaitez étudier hors ligne.

### Mes données ne se synchronisent pas

**Solution :** Vérifiez votre connexion Internet. Ouvrez le tableau de bord de synchronisation pour voir les détails des erreurs. Cliquez sur "Réessayer" pour les mutations échouées. Si le problème persiste, essayez de vous reconnecter.

### Je reçois une erreur de stockage plein

**Solution :** Allez dans Paramètres → Gestion du cache et supprimez les anciennes données ou le contenu en cache que vous n'utilisez plus. Kurama supprimera automatiquement les données les moins récemment utilisées si nécessaire.

### L'application est lente

**Solution :** Essayez de vider le cache et de redémarrer l'application. Si vous avez beaucoup de données en cache, supprimez les leçons que vous n'utilisez plus. Assurez-vous que votre appareil a suffisamment de mémoire disponible.

### Je ne peux pas me connecter

**Solution :** Vérifiez votre connexion Internet. Assurez-vous que vous utilisez un compte Google valide. Essayez de vider le cache de votre navigateur et de vous reconnecter. Si le problème persiste, contactez le support.

### Mes réponses ne sont pas enregistrées

**Solution :** Vérifiez que vous êtes connecté. Vos réponses sont enregistrées localement même hors ligne. Elles seront synchronisées quand vous serez en ligne. Consultez le tableau de bord de synchronisation pour voir le statut.

### Je vois un message "Conflit de données"

**Solution :** Cela signifie que vos données ont été modifiées sur plusieurs appareils. Kurama utilise la stratégie "dernière écriture gagne". Vos modifications locales les plus récentes seront conservées. Consultez le tableau de bord de synchronisation pour plus de détails.

## Questions fréquentes

### Puis-je utiliser Kurama sur plusieurs appareils ?

Oui ! Vos données sont synchronisées entre tous vos appareils. Connectez-vous avec le même compte Google sur chaque appareil.

### Que se passe-t-il si je supprime l'application ?

Vos données de progression sont sauvegardées sur nos serveurs. Quand vous réinstallez l'application et vous reconnectez, toutes vos données seront restaurées.

### Combien de temps mes données sont-elles conservées ?

Vos données de progression sont conservées indéfiniment. Les données en cache sont conservées pendant 7 jours d'inactivité, puis supprimées automatiquement pour libérer de l'espace.

### Mes données sont-elles sécurisées ?

Oui. Vos données sensibles (tokens d'authentification) sont chiffrées avant d'être stockées localement. Toutes les communications avec nos serveurs utilisent HTTPS.

### Puis-je partager mon compte avec quelqu'un d'autre ?

Non, chaque compte est personnel. Si vous avez plusieurs enfants, créez un compte séparé pour chacun avec une adresse e-mail différente.

### Comment puis-je exporter mes données ?

Actuellement, l'export de données n'est pas disponible. Vos données sont toujours accessibles via votre compte Kurama. Contactez le support si vous avez besoin d'une export spéciale.

### Que faire si je perds ma connexion Internet pendant une session d'étude ?

Pas de problème ! Continuez à étudier. Vos réponses seront enregistrées localement et synchronisées automatiquement quand vous serez en ligne.

### Puis-je étudier le même contenu sur plusieurs appareils en même temps ?

Oui, mais vos réponses seront synchronisées. Si vous répondez à la même question sur deux appareils, la dernière réponse sera conservée.
