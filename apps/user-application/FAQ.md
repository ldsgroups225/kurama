# Questions Fréquemment Posées (FAQ) - Kurama

## Installation et Configuration

### Comment installer Kurama ?

Kurama est une Progressive Web App (PWA) qui peut être installée sur votre appareil :

**Sur navigateur desktop :**
1. Ouvrez Kurama dans votre navigateur
2. Cliquez sur l'icône d'installation dans la barre d'adresse
3. Confirmez l'installation

**Sur iPhone :**
1. Ouvrez Kurama dans Safari
2. Appuyez sur le bouton Partager
3. Sélectionnez "Ajouter à l'écran d'accueil"
4. Appuyez sur "Ajouter"

**Sur Android :**
1. Ouvrez Kurama dans Chrome
2. Appuyez sur le menu (trois points)
3. Sélectionnez "Installer l'application"
4. Confirmez l'installation

### Puis-je utiliser Kurama sans l'installer ?

Oui, vous pouvez utiliser Kurama directement dans votre navigateur. Cependant, l'installation offre une meilleure expérience et permet d'utiliser l'application hors ligne.

### Kurama fonctionne-t-il sur tous les navigateurs ?

Kurama fonctionne mieux sur les navigateurs modernes :
- Chrome/Chromium (recommandé)
- Firefox
- Safari
- Edge

Les anciennes versions de navigateurs peuvent avoir des problèmes. Mettez à jour votre navigateur à la dernière version.

## Utilisation et Fonctionnalités

### Comment puis-je étudier hors ligne ?

1. Utilisez d'abord Kurama en ligne pour mettre en cache le contenu
2. Ouvrez une leçon
3. Cliquez sur "Télécharger pour l'étude hors ligne"
4. Attendez que le téléchargement soit terminé
5. Vous pouvez maintenant étudier hors ligne

### Que se passe-t-il si je perds ma connexion Internet pendant une session d'étude ?

Pas de problème ! Continuez à étudier. Vos réponses seront enregistrées localement et synchronisées automatiquement quand vous serez en ligne.

### Mes données sont-elles sauvegardées si je ferme l'application ?

Oui, vos données sont toujours sauvegardées. Vos réponses et votre progression sont enregistrées localement et synchronisées avec nos serveurs.

### Puis-je utiliser Kurama sur plusieurs appareils ?

Oui ! Vos données sont synchronisées entre tous vos appareils. Connectez-vous avec le même compte Google sur chaque appareil.

### Que se passe-t-il si je réponds à la même question sur deux appareils ?

Vos réponses seront synchronisées. Si vous répondez à la même question sur deux appareils, la dernière réponse sera conservée (stratégie "dernière écriture gagne").

### Comment puis-je voir mon XP et mes niveaux ?

Allez dans Paramètres → Profil pour voir votre XP, votre niveau actuel et votre progression vers le prochain niveau.

### Comment puis-je voir mes succès ?

Allez dans Paramètres → Succès pour voir tous vos succès et réalisations.

### Comment puis-je voir mon classement ?

Allez dans Paramètres → Classement pour voir votre position dans le classement global.

## Synchronisation et Données

### Comment fonctionne la synchronisation ?

Kurama synchronise automatiquement vos données quand vous êtes en ligne :
- Vos réponses aux flashcards
- Votre XP et vos niveaux
- Vos succès et réalisations
- Votre progression générale

### Combien de temps prend la synchronisation ?

La synchronisation est généralement instantanée. Si vous avez beaucoup de données à synchroniser, cela peut prendre quelques secondes.

### Que faire si la synchronisation échoue ?

1. Vérifiez votre connexion Internet
2. Attendez quelques secondes - la synchronisation est automatique
3. Ouvrez le tableau de bord de synchronisation pour voir les détails
4. Cliquez sur "Réessayer" pour les mutations échouées

### Mes données sont-elles sécurisées ?

Oui. Vos données sensibles (tokens d'authentification) sont chiffrées avant d'être stockées localement. Toutes les communications avec nos serveurs utilisent HTTPS.

### Combien de temps mes données sont-elles conservées ?

- **Données de progression :** Conservées indéfiniment
- **Données en cache :** Conservées pendant 7 jours d'inactivité, puis supprimées automatiquement

### Que se passe-t-il si je supprime l'application ?

Vos données de progression sont sauvegardées sur nos serveurs. Quand vous réinstallez l'application et vous reconnectez, toutes vos données seront restaurées.

### Puis-je exporter mes données ?

Actuellement, l'export de données n'est pas disponible. Vos données sont toujours accessibles via votre compte Kurama. Contactez le support si vous avez besoin d'une export spéciale.

## Stockage et Espace

### Combien d'espace Kurama utilise-t-il ?

Cela dépend du contenu que vous téléchargez. En général :
- Application de base : 5-10 MB
- Contenu en cache : 50-500 MB selon les leçons téléchargées

### Quel est mon quota de stockage ?

Chaque appareil a une limite de stockage :
- **Desktop :** Généralement 50 MB à plusieurs GB
- **Mobile :** Généralement 50 MB à 500 MB

### Comment puis-je vérifier mon espace disponible ?

Allez dans Paramètres → Gestion du cache pour voir l'espace utilisé et disponible.

### Que faire si je manque d'espace ?

1. Allez dans Paramètres → Gestion du cache
2. Cliquez sur "Effacer les anciennes données" pour supprimer les données obsolètes
3. Ou cliquez sur "Effacer tout le cache" pour une suppression complète
4. Vous pouvez aussi supprimer des leçons individuelles

### L'effacement du cache supprime-t-il ma progression ?

Non, l'effacement du cache ne supprime pas votre progression. Vos données de progression sont synchronisées avec nos serveurs et seront restaurées quand vous vous reconnectez.

## Comptes et Authentification

### Comment puis-je me connecter ?

Cliquez sur "Se connecter" et sélectionnez "Continuer avec Google". Vous serez redirigé vers la page de connexion Google.

### Puis-je utiliser un compte autre que Google ?

Actuellement, seule l'authentification Google est supportée. Nous prévoyons d'ajouter d'autres options à l'avenir.

### Que faire si j'oublie mon mot de passe Google ?

Allez sur https://accounts.google.com/signin/recovery pour réinitialiser votre mot de passe Google.

### Puis-je partager mon compte avec quelqu'un d'autre ?

Non, chaque compte est personnel. Si vous avez plusieurs enfants, créez un compte séparé pour chacun avec une adresse e-mail différente.

### Comment puis-je me déconnecter ?

Allez dans Paramètres → Profil et cliquez sur "Se déconnecter".

### Que se passe-t-il quand je me déconnecte ?

Vos données locales seront supprimées pour des raisons de sécurité. Vos données de progression seront conservées sur nos serveurs et restaurées quand vous vous reconnectez.

## Profil et Paramètres

### Comment puis-je compléter mon profil ?

Lors de votre première connexion, vous serez guidé à travers un formulaire de profil. Vous devez sélectionner :
- Votre niveau scolaire
- Votre série (pour les lycéens)
- Vos matières

### Puis-je modifier mon profil après l'avoir complété ?

Oui, allez dans Paramètres → Profil pour modifier vos informations.

### Comment puis-je changer mon niveau scolaire ?

Allez dans Paramètres → Profil et sélectionnez un nouveau niveau scolaire.

### Comment puis-je ajouter ou supprimer des matières ?

Allez dans Paramètres → Profil et modifiez votre liste de matières.

## Problèmes et Dépannage

### Kurama ne fonctionne pas

Consultez notre guide de dépannage complet dans l'application ou en ligne.

### Je reçois une erreur

Notez le message d'erreur exact et contactez le support. Ouvrez les outils de développement (F12) et copiez les messages de la console.

### L'application est lente

Essayez de vider le cache et de redémarrer l'application. Si le problème persiste, vérifiez votre connexion Internet.

### Je ne peux pas me connecter

Vérifiez votre connexion Internet et assurez-vous que votre compte Google est actif. Essayez de vider le cache du navigateur.

### Mes données ne se synchronisent pas

Vérifiez votre connexion Internet et ouvrez le tableau de bord de synchronisation pour voir les détails des erreurs.

## Assistance

### Comment puis-je contacter le support ?

Allez dans Paramètres → Support ou envoyez un e-mail à support@kurama.app

### Quels sont les horaires du support ?

Notre équipe de support est disponible du lundi au vendredi, de 9h à 18h (heure d'Abidjan).

### Combien de temps faut-il pour obtenir une réponse ?

Nous répondons généralement dans les 24 heures.

### Puis-je signaler un bug ?

Oui, allez dans Paramètres → Support et cliquez sur "Signaler un bug". Décrivez le problème et incluez les étapes pour le reproduire.

### Puis-je suggérer une nouvelle fonctionnalité ?

Oui, allez dans Paramètres → Support et cliquez sur "Suggérer une fonctionnalité". Nous aimerions entendre vos idées !

## Confidentialité et Sécurité

### Mes données sont-elles privées ?

Oui, vos données sont privées et sécurisées. Nous ne partageons jamais vos données avec des tiers.

### Comment mes données sont-elles protégées ?

- Vos données sensibles sont chiffrées avant d'être stockées
- Toutes les communications utilisent HTTPS
- Nous suivons les meilleures pratiques de sécurité

### Puis-je supprimer mes données ?

Oui, allez dans Paramètres → Confidentialité et cliquez sur "Supprimer mon compte". Cela supprimera toutes vos données.

### Kurama collecte-t-il mes données personnelles ?

Nous collectons uniquement les données nécessaires pour fournir le service :
- Votre nom et votre adresse e-mail (via Google)
- Votre profil scolaire
- Votre progression d'étude

Nous ne vendons jamais vos données.
